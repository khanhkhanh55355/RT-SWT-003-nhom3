Authoring Gherkin scenarios manually is labor-intensive, requiring testers to translate informal requirements into precise, executable acceptance criteria and accounting for a substantial share of software testing effort. Although recent work has explored large language models for Behaviour-Driven Development, no prior study has evaluated generated Gherkin using automated quantitative metrics combined with statistical significance testing. We evaluate GPT-4o in a zero-shot setting on 100 user story--Gherkin pairs from Rathnayake et al.~(2026), using Cosine Semantic Similarity with a threshold of $\geq 0.85$ and Executable Syntax Rate with a threshold of $\geq 80\%$, validated by one-tailed Wilcoxon signed-rank and Binomial exact tests. GPT-4o achieves a 100\% executable syntax rate (RQ2 passed, $p=2.04\times10^{-10}$), but does not reach the semantic similarity threshold (RQ1 failed, median cosine similarity $=0.774$, $p\approx1.00$, and Cliff's $\delta=-0.70$). These findings indicate that GPT-4o reliably produces syntactically valid Gherkin scenarios, but practitioners should retain human review to verify semantic accuracy, completeness, and alignment with the original user-story intent.
